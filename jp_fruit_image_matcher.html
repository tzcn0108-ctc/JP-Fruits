為何要用 GitHub 放圖片？

供應商圖片（HK Dim Sum、Kuji、Bobo）可能因為 CORS 政策而無法喺客戶網站顯示。 將圖片放喺你自己嘅 GitHub repository 最穩定可靠，而且永遠免費（1GB 空間）。

1
喺 GitHub 建立 images 資料夾
去 github.com/tzcn0108-ctc/JP-Fruits → 撳「Add file」→「Create new file」→ 輸入 images/.gitkeep → Commit
2
下載供應商圖片
撳下面「下載供應商圖片清單」按鈕，逐個右鍵圖片「另存新檔」到你電腦一個資料夾，建議命名為中文產品名（例如：燒賣.jpg）
3
上傳到 GitHub images 資料夾
去 github.com/tzcn0108-ctc/JP-Fruits/tree/main/images → 「Add file」→「Upload files」→ 選擇全部圖片 → Commit
4
圖片連結格式
上傳後，圖片連結格式係：
https://tzcn0108-ctc.github.io/JP-Fruits/images/燒賣.jpg
可以直接貼入 CMS 產品圖片欄位。
5
用配對工具（你的相片 Tab）更新連結
上傳相片後在「你的相片」Tab 配對產品，然後匯出代碼更新網站。
